Original package README notices are retained alongside local weights.
Exact download URLs, versions and archive SHA-256 digests are recorded
in tmp/offline-i18n/models.json. Model files and the Python runtime
remain local build tools and are never copied into website assets.

Locally generated translations are drafts. Structural, numeric, placeholder,
license-identifier and language-script checks do not establish linguistic
accuracy. Drafts are excluded from native coverage until reviewed against
their exact English source; completed pages must also pass initial SSR HTML
verification. There is no visitor-time model execution or paid API request.
